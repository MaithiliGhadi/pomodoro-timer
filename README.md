# Pomodoro Timer

A simple browser-based Pomodoro productivity timer built with HTML, CSS and JavaScript.

## Features

- 25-minute work timer
- 5-minute short break
- 15-minute long break
- Start / pause / reset controls
- Completed work-session counter
- Responsive UI
- Accessible button focus states
- Browser tab timer display

## Project Structure

```text
pomodoro-timer/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
├── .gitignore
└── README.md
```

## Run Locally

No build tool or package manager is required.

1. Clone the repository.
2. Open the project in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
